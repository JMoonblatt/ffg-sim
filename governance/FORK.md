# Fork-first rule

Disagreement is resolved by parallel experiment, not personality conflict.

## When to fork
Fork if:
- A proposal is blocked for > 72 hours AND
- The disagreement is about outcomes/strategy (not a bug/fact)

## How to fork
- Create two branches/plans: A and B
- Each branch must define the same metric and evaluation window
- Default evaluation window: 2–4 weeks

## Merge rule
At the end of the window:
- Merge the branch that best matches the metric
- Archive the other with credit preserved
- Log the outcome in DL.md

## Fork budget (anti-fragmentation)
- Maximum concurrent forks: 2
- A fork must end (merge/archive) before a new one begins, unless steward approves
